## Translation fidelity

When translating or adapting source material for this repository, treat the source as authoritative.

- Preserve all meaningful source content and keep the original structure and order whenever practical, including headings, paragraphs, examples, Bad / Good comparisons, code, links, quotes, tables, callouts, and other semantically relevant elements.
- Do not silently summarize, omit, merge, or rewrite away source material unless the user explicitly asks for an abridged or adapted version.
- Do not invent claims, explanations, examples, or conclusions that are not present in the source. If an editorial note is genuinely necessary, label it clearly as an editor/translator note so it cannot be confused with the source.
- Translate as faithfully as possible while keeping the target language natural. Preserve technical names, identifiers, commands, paths, code, and other tokens when translating them would reduce accuracy.
- If the source uses a visual presentation that cannot be reproduced directly, use an equivalent MyST / Sphinx Design component or a small CSS treatment rather than dropping the content.
- Before finishing a translation, compare the result against the source once more and check specifically for omissions, unsupported additions, missing examples, and altered meaning.
